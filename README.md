# CTF_competition_writeups

A personal collection of CTF competition writeups, solve scripts, and challenge notes. The repository is organized by competition/event.

## Repository Structure

```text
CTF_competition_writeups/
├── MyFirstCTF/
│   ├── AIS3_Hidden_in_the_Cloak_writeup.pdf
│   ├── AIS3_reverse_lua_opcode_shuffle_writeup.pdf
│   ├── AIS3_哇金色傳說_writeup.pdf
│   ├── blooock_solve.py
│   └── blooockchain_writeup.pdf
└── README.md
```

## Included Content

| Path | Description |
|---|---|
| `MyFirstCTF/` | Writeups and solve scripts from the MyFirstCTF event. |
| `*.pdf` | Completed writeup documents. |
| `blooock_solve.py` | Python solve script for a challenge. |

## Usage

Clone the repository:

```bash
git clone https://github.com/Ian684/CTF_competition_writeups.git
cd CTF_competition_writeups
```

Open a writeup PDF:

```bash
cd MyFirstCTF
```

Run a solve script when applicable:

```bash
python3 blooock_solve.py
```

Some scripts may require original challenge files, remote service information, or additional setup depending on the challenge.
